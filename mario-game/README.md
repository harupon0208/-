# スーパージャンプクエスト

マリオ風の2D横スクロールアクションゲーム。全9ステージで、後半ほど難しくなる。
HTML5 Canvas + バニラ JavaScript 製(ライブラリ・ビルド不要)。

## 遊び方

`index.html` をブラウザで開くだけ(ダブルクリックでOK、サーバー不要)。

| 操作 | キー |
|---|---|
| 移動 | ← → または A D |
| ジャンプ | スペース / ↑ / W(長押しで高くジャンプ) |

- 敵は上から踏むと倒せる。横から触れるとダメージ。
- キノコを取ると大きくなり、1回だけダメージに耐えられる。
- 旗に触れるとステージクリア。残機3でスタート。
- ステージ9はボス戦。3回踏めば勝ち。

## ステージ構成

1. チュートリアル(平坦・狭い穴)
2. 段差と浮き足場
3. 高速敵が登場
4. 横に動く足場
5. 跳ねる敵と狭い足場
6. 縦に動く足場と高台
7. 動く足場の乗り継ぎ
8. 全要素の総合ステージ
9. ボス戦

## デバッグ機能

- `index.html?stage=5` … ステージ5から開始
- プレイ中に数字キー 1〜9 … そのステージへ即移動

## ファイル構成

`js/` 以下に責務ごとに分割。`index.html` の `<script>` の順番が依存順
(file:// で動かすため ES modules は不使用)。

- `config.js` 定数 / `input.js` 入力 / `levels.js` ステージデータ
- `level.js` タイルマップと当たり判定 / `camera.js` カメラ
- `player.js` プレイヤー / `enemies.js` 敵とボス / `items.js` アイテムと動く足場
- `game.js` 状態管理・ゲームループ・HUD

ステージは `levels.js` のタイルマップ(1文字=1タイル)で定義。記号の意味は同ファイル冒頭のコメント参照。
