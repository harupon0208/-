# スーパージャンプクエスト

マリオ風の2D横スクロールアクションゲームです。茶髪の冒険者を操作して、敵をよけたり踏んだりしながらゴールの旗を目指します。全9ステージあり、後半ほど穴が広く・足場が狭く・敵が増えて難しくなります。

**技術:** HTML5 Canvas + バニラ JavaScript のみ。ライブラリもビルド(npm など)も不要で、**画像ファイルも音声ファイルも一切使いません**。グラフィックはすべて図形をその場で描き、効果音・BGMは Web Audio API でその場で合成しています。進行状況やベストスコアはブラウザの localStorage に保存され、スマホ対応(画面ボタン)も入っています。

---

## 1. 起動方法

`index.html` をダブルクリックしてブラウザ(Chrome / Safari / Edge など)で開くだけです。インストールもローカルサーバーも要りません。

> もし開いても真っ白なときは、ブラウザのウィンドウをクリックしてからキーを押してみてください(キー入力を受け取るためにページにフォーカスが必要です)。

---

## 2. 操作方法

| やりたいこと | キー |
|---|---|
| 左右に歩く・走る | `←` `→` または `A` `D` |
| ジャンプ | `スペース` / `↑` / `W` |
| 高くジャンプ | ジャンプキーを**長く押す**(短く押すと低いジャンプ) |
| 壁キック | 空中で**壁の方を押しながらジャンプ** |
| 画面を進める(タイトル・選択・クリアなど) | `スペース` |
| ポーズ(一時停止) | `P` または `Esc`、または画面右上の ⏸ ボタン |
| 音のオン/オフ | `M` キー、または画面右上の 🔊 ボタン |
| 進行状況を最初からリセット | タイトル画面で `R` |

> 効果音・BGMは最初のキー操作/タップで鳴り始めます(ブラウザの自動再生ルール対策)。面ごとに背景テーマ(草原→昼の丘→夕暮れ→雲海→夜の森→洞窟→雪原→遺跡→溶岩のボス)が変わり、霧・光・浮遊する粒子などの雰囲気が切り替わります。

> **スマホの場合:** 画面の左下に「◀ ▶」、右下に「JUMP」ボタンが自動で表示されます(PCでは表示されません)。JUMPボタンはジャンプ兼「決定」で、タイトルやステージ選択もこのボタンで進められます。右上の ⏸(ポーズ)・🔊(音)ボタンも常に表示されます。

### ポーズメニュー
`P` / `Esc` / ⏸ ボタンで一時停止すると、「つづける」「マップへもどる」を ←→ で選び、`スペース`(JUMPボタン)で決定できます。

### ジャンプのコツ
- ボタンを押している長さでジャンプの高さが変わります(長押しで高く飛ぶ)。
- 足場のふちから落ちた直後でも、ほんの一瞬だけジャンプを受け付けます(ギリギリのジャンプが決めやすい)。
- 着地のちょっと前にジャンプを押しておくと、着地と同時に自動でジャンプします(連続ジャンプがしやすい)。

### 壁キックのやり方
1. 空中で壁に向かって移動キーを押し続けると、壁にはりついてゆっくりずり落ちます。
2. その状態で**ジャンプ**を押すと、壁を蹴って反対側ななめ上へ飛びます。
3. 左右の壁を交互に蹴れば、上へ登っていけます。ステージ9のボス部屋(左右に壁がある)が練習にぴったりです。

## 3. ゲームの流れ

```
タイトル → ステージ選択(ワールドマップ) → ステージをプレイ
              ↑                              │
              └──── 死んでも/クリアしても戻る ───┘
```

1. **タイトル画面**でスペースを押すと、**ステージ選択画面**(草原のワールドマップ)に進みます。
2. 選択画面では `←` `→` で遊ぶ面を選び、`スペース`で開始します。面に入るときに「READY? → GO!」の合図が出ます。
3. ステージをクリア(ゴールの旗に触れる)すると、花火が上がり、**次の面が解放**されて選択画面に戻ります。
4. **ゲームオーバーはありません。** 死んでも選択画面に戻るだけなので、何度でも挑戦できます。
5. 最後のステージ9でボスを倒すと、全クリア画面になります。

### 進行状況のセーブ
クリアした面・解放された面・**ベストスコア**は自動で保存されます(ブラウザの localStorage)。タブを閉じて開き直しても**続きから**遊べ、タイトルにベストスコアが表示されます。最初からやり直したいときはタイトルで `R` を押します。

### ステージ選択画面の見方
- **黄色い丸+番号** … 今プレイできる面。
- **緑の丸+旗** … クリア済みの面。
- **灰色の丸+カギ** … まだ解放されていない面(クリアして進めると開きます)。
- **赤い丸+ドクロ** … ステージ9(ボス戦)。
- 選んでいる面の上に冒険者が乗っていて、画面下に面の名前が出ます。

## 4. ルール・遊び方の基本

- **敵をたおす:** 敵の**上から踏む**とたおせます。横や下から触れるとダメージを受けます。
- **パワーアップ:** キノコを取ると体が大きくなり、**1回だけダメージに耐えられます**。
  - 大きい状態でダメージを受けると、たおれずに小さい状態へ戻ります(少しのあいだ無敵で点滅)。
  - 小さい状態でダメージを受けたり、穴に落ちるとミス(選択画面に戻る)。
- **ゴール:** ステージ右の**旗**に触れるとクリアです。
- **スコア:** 敵を踏む(+100)、キノコを取る(+200)、ボスに当てる(+500)、ステージクリア(+1000)で増えます。画面右上に表示。

### 出てくる敵
| 敵 | 見た目 | 特徴 |
|---|---|---|
| 歩行敵(Walker) | 茶色 | ゆっくり歩く。崖で引き返す。 |
| 高速敵(Speedy) | 赤色 | 速く動く。崖があっても止まらず落ちる。 |
| 跳ね敵(Hopper) | 緑色 | こちらに向かってピョンピョン跳ねる。踏みにくい。 |
| ボス | 紫色(ツノ) | ステージ9のみ。歩いて近づき、ジャンプして弾を撃つ。**3回踏めば勝ち**(ダメージを与えるほど動きが激しくなる)。 |

## 6. デバッグ・確認用の機能

開発中に動作を確かめるための機能です。

- **特定の面から始める:** URLの後ろに付けます。例 → `index.html?stage=5`(5面から開始。全面が解放された状態になります)
- **プレイ中に面を移動:** 数字キー `1`〜`9` を押すと、その面へすぐ飛びます。

## 7. ファイル構成

`js/` の中を役割ごとに分けています。`index.html` の `<script>` の**読み込み順がそのまま依存順**です(`file://` で動かすため、あえて ES modules は使わずグローバル変数で連携しています)。

読み込み順:`config → gfx → themes → input → audio → levels → level → camera → items → enemies → player → game`。

| ファイル | 役割 |
|---|---|
| `config.js` | 物理や難易度などの**定数**(ジャンプ力・重力・壁キックの強さ など) |
| `gfx.js` | 描画のヘルパー(角丸・影・発光)と**パーティクル**(土ぼこり・キラキラ・花火・スコア表示) |
| `themes.js` | 面ごとの**背景テーマ**(空・霧・ビネット・浮遊粒子・タイルの配色)。重い描画は1枚に焼いて使い回し**軽量化** |
| `input.js` | キーボード**入力**の管理(画面ボタンもここに流し込む) |
| `audio.js` | **効果音・BGM**(Web Audio で合成)とミュート |
| `levels.js` | 全9ステージの**マップデータ** |
| `level.js` | マップの読み込み・描画・**当たり判定** |
| `camera.js` | 横スクロール**カメラ** |
| `player.js` | **プレイヤー**(移動・ジャンプ・壁キック・見た目) |
| `enemies.js` | **敵とボス**、ボスの弾 |
| `items.js` | キノコ・ゴール旗・**動く足場** |
| `game.js` | **全体の進行管理**(タイトル/選択/READY/プレイ/ポーズ/クリア)・ゲームループ・HUD・セーブ |

> **動作の安定:** ゲームループは「固定タイムステップ」方式なので、60Hz でも 120Hz の画面でも**同じ速さ**で動きます。背景タイル・ビネット・発光はあらかじめ画像に焼いて毎フレーム貼り回すことで、軽快に動くようにしています。

## 8. カスタマイズの仕方(自分でいじってみる)

### ステージを作り変える
`levels.js` の中で、各ステージは**1文字=1マス(タイル)**の文字の並びで作られています。記号の意味は次のとおり(詳しくは `levels.js` の先頭コメントに記載)。

| 記号 | 意味 |
|---|---|
| `.` | 空(なにもない空間) |
| `#` | 地面・ブロック |
| `=` | 浮き足場ブロック |
| `P` | プレイヤーのスタート位置 |
| `G` | ゴールの旗 |
| `*` | キノコ(パワーアップ) |
| `e` / `f` / `j` | 歩行敵 / 高速敵 / 跳ね敵 |
| `-` / `\|` | 横に動く足場 / 縦に動く足場 |
| `B` | ボス(ステージ9用) |

穴を広げたい・敵を増やしたいときは、この記号を書き換えるだけで調整できます。

### 操作感を変える
`config.js` の数値を変えると手ざわりが変わります。例:
- `JUMP_VEL` … ジャンプの高さ(マイナスが大きいほど高く飛ぶ)
- `MOVE_SPEED` … 走る速さ / `MOVE_ACCEL`・`TURN_ACCEL` … 加速・切り返しのキビキビ感
- `GRAVITY` / `FALL_GRAVITY` … 上昇中・落下中の重力(落下を重くするとキビキビする)
- `COYOTE` / `JUMP_BUFFER` … 足場のふちを過ぎてもジャンプできる猶予 / 着地前の先行入力
- `WALL_KICK_VX` / `WALL_KICK_VY` … 壁キックで飛ぶ強さ(横/上)
- `WALL_SLIDE_SPEED` … 壁ずりで落ちる速さ

### 背景テーマを変える
`themes.js` の `THEMES` 配列に、面ごとの空の色・霧・ビネット・浮遊粒子・タイルの配色がまとまっています。色を書き換えれば、その面の世界観を丸ごと変えられます。

### 効果音・BGM を変える
`audio.js` の `play()`(各効果音)と `startBGM()`(メロディの数値の並び)を変えると、音を調整できます。
