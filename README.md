# スーパージャンプクエスト

マリオ風の2D横スクロールアクションゲームです。茶髪の冒険者を操作して、敵をよけたり踏んだりしながらゴールの旗を目指します。**全3ワールド・全27ステージ**(地上 → 空と氷雪 → 魔界と溶岩)で、各ワールドの最後には**そのワールド固有のボス**が待ち受けます。後のワールドほど穴が広く・足場が狭く・ギミックが増えて難しくなります。

**技術:** HTML5 Canvas + バニラ JavaScript のみ。ライブラリもビルド(npm など)も不要で、**画像ファイルも音声ファイルも一切使いません**。グラフィックはすべて図形をその場で描き、効果音・BGMは Web Audio API でその場で合成しています。進行状況やベストスコアはブラウザの localStorage に保存され、スマホ対応(画面ボタン)も入っています。

**主な要素:** 3ワールド構成・ワールドごとの世界観とボス、3種のパワーアップ(キノコ/ファイアフラワー/フェザー)、残機制(コイン100枚で1UP)、無敵スター、中間チェックポイント、連続踏みつけコンボ。ギミックはバネ・崩れる足場・氷の床(滑る)・上昇気流・大砲・トゲ/溶岩ハザード。画面ゆれを抑える「モーション軽減」設定(光過敏配慮)と、ブラウザ不要で動く軽量な自動テスト(`npm test`)つき。

---

## 1. 起動方法

`index.html` をダブルクリックしてブラウザ(Chrome / Safari / Edge など)で開くだけです。インストールもローカルサーバーも要りません。

> もし開いても真っ白なときは、ブラウザのウィンドウをクリックしてからキーを押してみてください(キー入力を受け取るためにページにフォーカスが必要です)。

## 2. 操作方法

| やりたいこと | キー |
|---|---|
| 左右に歩く・走る | `←` `→` または `A` `D` |
| ジャンプ | `スペース` / `↑` / `W` |
| 高くジャンプ | ジャンプキーを**長く押す**(短く押すと低いジャンプ) |
| 壁キック | 空中で**壁の方を押しながらジャンプ** |
| 二段ジャンプ・滑空 | **フェザー**取得中: 空中でもう一度ジャンプ / 落下中にジャンプ長押しで滑空 |
| 火球を撃つ | **ファイアフラワー**取得中: `X` / `Z` / `Shift`、またはスマホの 🔥 ボタン |
| 画面を進める(タイトル・選択・クリアなど) | `スペース` |
| ポーズ(一時停止) | `P` または `Esc`、または画面右上の ⏸ ボタン |
| 音のオン/オフ | `M` キー、または画面右上の 🔊 ボタン |
| モーション軽減(画面ゆれ抑制)の切替 | タイトル画面で `V`、またはポーズメニュー |
| 進行状況を最初からリセット | タイトル画面で `R` |

> 効果音・BGMは最初のキー操作/タップで鳴り始めます(ブラウザの自動再生ルール対策)。面ごとに背景テーマ(草原→昼の丘→夕暮れ→雲海→夜の森→洞窟→雪原→遺跡→溶岩のボス)が変わり、霧・光・浮遊する粒子などの雰囲気が切り替わります。

> **スマホの場合:** 画面の左下に「◀ ▶」、右下に「JUMP」ボタンが自動で表示されます(PCでは表示されません)。JUMPボタンはジャンプ兼「決定」で、タイトルやステージ選択もこのボタンで進められます。右上の ⏸(ポーズ)・🔊(音)ボタンも常に表示されます。

### ポーズメニュー
`P` / `Esc` / ⏸ ボタンで一時停止すると、「つづける」「モーション軽減: ON/OFF」「マップへもどる」を `↑` `↓`(または `W` `S`)で選び、`スペース`(JUMPボタン)で決定できます。「モーション軽減」は決定するたびに切り替わり、ポーズはそのまま続きます。

> **モーション軽減について:** ONにすると、敵を踏んだ時などの**画面ゆれが止まり、フラッシュもごく弱く**なります(光の点滅が苦手な方向け)。設定は保存され、初回はOSの「視差効果を減らす / アニメーション軽減」設定があれば自動でONになります。

### ジャンプのコツ
- ボタンを押している長さでジャンプの高さが変わります(長押しで高く飛ぶ)。
- 足場のふちから落ちた直後でも、ほんの一瞬だけジャンプを受け付けます(ギリギリのジャンプが決めやすい)。
- 着地のちょっと前にジャンプを押しておくと、着地と同時に自動でジャンプします(連続ジャンプがしやすい)。

### 壁キックのやり方
1. 空中で壁に向かって移動キーを押し続けると、壁にはりついてゆっくりずり落ちます。
2. その状態で**ジャンプ**を押すと、壁を蹴って反対側ななめ上へ飛びます。
3. 左右の壁を交互に蹴れば、上へ登っていけます。ステージ9のボス部屋(左右に壁がある)が練習にぴったりです。

## 3. ゲームの流れ

```
タイトル → ステージ選択(ワールドマップ) → ステージをプレイ
              ↑                              │
              └──── 死んでも/クリアしても戻る ───┘
```

1. **タイトル画面**でスペースを押すと、**ステージ選択画面**(横に長いワールドマップ)に進みます。マップは選んでいる面に合わせて自動で横スクロールし、画面右上に今いる**ワールド(1〜3)**が出ます。
2. 選択画面では `←` `→` で遊ぶ面を選び、`スペース`で開始します。面に入るときに「READY? → GO!」の合図が出ます。
3. ステージをクリア(ゴールの旗に触れる)すると、花火が上がり、**次の面が解放**されて選択画面に戻ります。
4. **残機(ライフ)制です。** ミスすると残機が1減り、**チェックポイントを通っていればそこから**、無ければ面の最初から再開します。残機が尽きると **GAME OVER** になり、タイトルへ戻ります(進行状況は保存済みなので続きから挑戦できます)。
   - 残機は **コインを100枚集めるごとに +1**(画面左上にハート♥で表示)。
   - 残機は遊んでいる間ずっと持ち越され、新しく遊び始めると `START_LIVES`(初期3)に戻ります。
5. **3ワールド構成**で、各ワールドの9面目が**ボス**です(ワールドごとに見た目・攻撃・HPが違う別ボス)。最後のワールド3のボス「冥王」を倒すと、全クリア画面になります。

### 進行状況のセーブ
クリアした面・解放された面・**ベストスコア**は自動で保存されます(ブラウザの localStorage)。タブを閉じて開き直しても**続きから**遊べ、タイトルにベストスコアが表示されます。最初からやり直したいときはタイトルで `R` を押します。セーブデータには**バージョン番号**が入っており、将来フォーマットが変わっても古いデータを読み込めるようにしています。

> 残機・コイン枚数・コンボはステージをまたぐ「1回の挑戦」の中だけのもので、セーブ対象ではありません(セーブされるのは解放状況・クリア状況・ベストスコアと、別枠で音/モーション軽減の設定です)。

### ステージ選択画面の見方
- **色つきの丸+番号** … 今プレイできる面。丸の色は**ワールドごと**に変わります(W1=黄/W2=水色/W3=紫)。番号はワールド内の番号(1〜8)。
- **緑の丸+旗** … クリア済みの面。
- **灰色の丸+カギ** … まだ解放されていない面(クリアして進めると開きます)。
- **赤い丸+ドクロ** … 各ワールドのボス面(9面目)。
- 選んでいる面の上に冒険者が乗っていて、画面下に面の名前、右上にワールド名が出ます。

## 4. ルール・遊び方の基本

- **敵をたおす:** 敵の**上から踏む**とたおせます。横や下から触れるとダメージを受けます。
- **踏みつけコンボ:** 着地せずに**続けて敵を踏む**と、得点が `+100 → +200 → +400 …` と倍々に増えます(画面中央に「COMBO xN」表示)。地面に着くとリセット。
- **パワーアップ(3種):** どれも体が大きくなり、**1回ダメージに耐えられます**(ダメージを受けると小さい状態へ戻る・少しのあいだ無敵で点滅)。小さい状態でダメージ/穴に落ちる/ハザードに触れるとミス(残機-1)。
  - **キノコ(`*`):** 大きくなる(基本のパワーアップ)。
  - **ファイアフラワー(`F`):** `X`/`Z`/`Shift`(スマホは🔥)で**火球**を撃てる。火球は地面で弾み、敵に当てて倒せる。ワールド3で初登場。
  - **フェザー(`V`):** 空中で**二段ジャンプ**、落下中にジャンプ長押しで**滑空**。立体的な足場越えに。ワールド2で初登場。
  - 現在のパワーは画面左上に「POWER / FIRE / CAPE」と表示。
- **コイン(`o`):** 集めると得点。**100枚で残機+1**。画面左上にコイン枚数が出ます。
- **無敵スター(`s`):** 取ると一定時間**無敵**になり、触れるだけで敵をたおせます(虹色オーラ+専用BGM)。残り時間は画面上部のバーで表示され、終わりが近づくと点滅します。
- **チェックポイント(`C`):** 触れると旗が緑に変わり、その面でミスしたときの**復活地点**になります(長いステージに設置)。
- **ゴール:** ステージ右の**旗**に触れるとクリアです。
- **スコア:** コイン(+50)、敵を踏む(+100〜コンボで倍増)、キノコ/ファイア/フェザー(+200)、スター(+300)、ボスに当てる(+500/火球+200)、ステージクリア(+1000)で増えます。画面右上に表示。

### しかけ(ギミック)
- **バネ(`^`):** 上に乗ると**高く跳ねる**。届かない足場へ。
- **崩れる足場(`:`):** 乗るとすぐ崩れて落ちる。**長居は禁物**(少し待つと復活)。
- **氷の床(W2の氷ステージ):** 地面が**滑る**。止まりにくいので加速に注意。
- **上昇気流(`w`):** 風の柱に入ると**上へ押し上げられる**。高所のコインや足場へ。
- **大砲(`>` `<`):** 一定間隔で**弾を撃つ**。弾はプレイヤーに当たるとダメージ。タイミングを見て進む。
- **ハザード(`x` トゲ/溶岩):** 触れると**即ミス**。ワールド3で多用。

### 出てくる敵
| 敵 | 見た目 | 特徴 |
|---|---|---|
| 歩行敵(Walker) | 茶色 | ゆっくり歩く。崖で引き返す。 |
| 高速敵(Speedy) | 赤色 | 速く動く。崖があっても止まらず落ちる。 |
| 跳ね敵(Hopper) | 緑色 | こちらに向かってピョンピョン跳ねる。踏みにくい。 |

各ワールドのボスは別物で、HPが減るほど激化します。**上から踏むか火球を当てて**HPを削れば勝ち。

| ボス | ワールド | HP | 特徴 |
|---|---|---|---|
| 魔王 | W1(溶岩) | 3 | 紫・ツノ。歩いて近づきジャンプして弾を撃つ。 |
| 氷帝 | W2(氷結) | 4 | 青白・氷の角。動きが速く、弾を扇状に撃つ。 |
| 冥王 | W3(煉獄) | 5 | 赤黒・3本ツノ。最速で、斜め下に降り注ぐ弾も。 |

## 5. ワールド構成(難易度の上がり方)

全3ワールド × 各9面 = 27面。各ワールドの9面目がボス。

| ワールド | 世界観 | 主な内容 |
|---|---|---|
| **W1(1〜9)** | 地上の自然(草原〜溶岩) | 基本操作・キノコ・スター。9面目で魔王戦。 |
| **W2(10〜18)** | 空と氷雪 | フェザー初登場。バネ・崩れる足場・上昇気流・氷の床・大砲。9面目で氷帝戦。 |
| **W3(19〜27)** | 魔界と溶岩 | ファイアフラワー初登場。トゲ/溶岩ハザード・大砲密集・崩れる足場。9面目で冥王戦。 |

## 6. デバッグ・確認用の機能

開発中に動作を確かめるための機能です。

- **特定の面から始める:** URLの後ろに付けます。例 → `index.html?stage=5`(5面から開始。全面が解放された状態になります)
- **プレイ中に面を移動:** 数字キー `1`〜`9` を押すと、その面へすぐ飛びます。

## 7. ファイル構成

`js/` の中を役割ごとに分けています。`index.html` の `<script>` の**読み込み順がそのまま依存順**です(`file://` で動かすため、あえて ES modules は使わずグローバル変数で連携しています)。

読み込み順:`config → gfx → themes → input → audio → levels → level → camera → items → enemies → player → game`。

| ファイル | 役割 |
|---|---|
| `config.js` | 物理や難易度などの**定数**(ジャンプ力・重力・壁キックの強さ など) |
| `gfx.js` | 描画のヘルパー(角丸・影・発光)と**パーティクル**(土ぼこり・キラキラ・花火・スコア表示) |
| `themes.js` | 面ごとの**背景テーマ**(空・霧・ビネット・浮遊粒子・タイルの配色)。重い描画は1枚に焼いて使い回し**軽量化** |
| `input.js` | キーボード**入力**の管理(画面ボタンもここに流し込む) |
| `audio.js` | **効果音・BGM**(Web Audio で合成)とミュート |
| `levels.js` | 全27ステージ(3ワールド)の**マップデータ** |
| `level.js` | マップの読み込み・描画・**当たり判定** |
| `camera.js` | 横スクロール**カメラ** |
| `player.js` | **プレイヤー**(移動・ジャンプ・壁キック・パワーアップ状態 small/big/fire/cape・二段ジャンプ/滑空/火球・見た目) |
| `enemies.js` | **敵とワールド別ボス(tier 1/2/3)**、ボスの弾 |
| `items.js` | キノコ・**ファイア/フェザー**・コイン・スター・チェックポイント・**バネ/崩れ足場/大砲/火球**・ゴール旗・動く足場 |
| `game.js` | **全体の進行管理**(タイトル/選択/READY/プレイ/ポーズ/クリア/ゲームオーバー)・ゲームループ・残機/コイン/コンボ・HUD・セーブ |

`js/` の外には、ブラウザを使わず純粋ロジック(設定・マップ解析・当たり判定)を検証する軽量テスト `tests/run.js` があります(下記「テスト」を参照)。

> **動作の安定:** ゲームループは「固定タイムステップ」方式なので、60Hz でも 120Hz の画面でも**同じ速さ**で動きます。背景タイル・ビネット・発光はあらかじめ画像に焼いて毎フレーム貼り回すことで、軽快に動くようにしています。

## 8. カスタマイズの仕方(自分でいじってみる)

### ステージを作り変える
`levels.js` の中で、各ステージは**1文字=1マス(タイル)**の文字の並びで作られています。記号の意味は次のとおり(詳しくは `levels.js` の先頭コメントに記載)。

| 記号 | 意味 |
|---|---|
| `.` | 空(なにもない空間) |
| `#` | 地面・ブロック |
| `=` | 浮き足場ブロック |
| `P` | プレイヤーのスタート位置 |
| `G` | ゴールの旗 |
| `*` | キノコ(パワーアップ) |
| `F` / `V` | ファイアフラワー(火球) / フェザー(二段ジャンプ+滑空) |
| `o` | コイン(100枚で残機+1。空中に置いて軌跡やジャンプ誘導に使う) |
| `s` | 無敵スター(地面で跳ね、壁で反転する) |
| `C` | 中間チェックポイント(復活地点) |
| `x` | ハザード(トゲ/溶岩・触れると即ミス・非固体) |
| `^` / `:` | バネ / 崩れる足場 |
| `>` / `<` | 右向き大砲 / 左向き大砲 |
| `w` | 風(上昇気流の列) |
| `e` / `f` / `j` | 歩行敵 / 高速敵 / 跳ね敵 |
| `-` / `\|` | 横に動く足場 / 縦に動く足場 |
| `B` | ボス(各ワールドの9面目 = index 8/17/26。ワールドで別tier) |

穴を広げたい・敵を増やしたいときは、この記号を書き換えるだけで調整できます。コイン・ハザード・風は空中(地面より上の行)に、その他は敵と同じく「立たせたい床のひとつ上の行」に置きます。氷で滑る床は記号ではなく**テーマ側の `tile.slippery`** で表現します。**ステージ数を増やしても**、ステージ選択画面は選んだ面に合わせて自動で横スクロールします(`themes.js` の `STAGE_THEME` でテーマ割り当ても拡張)。

### 操作感を変える
`config.js` の数値を変えると手ざわりが変わります。例:
- `JUMP_VEL` … ジャンプの高さ(マイナスが大きいほど高く飛ぶ)
- `MOVE_SPEED` … 走る速さ / `MOVE_ACCEL`・`TURN_ACCEL` … 加速・切り返しのキビキビ感
- `GRAVITY` / `FALL_GRAVITY` … 上昇中・落下中の重力(落下を重くするとキビキビする)
- `COYOTE` / `JUMP_BUFFER` … 足場のふちを過ぎてもジャンプできる猶予 / 着地前の先行入力
- `WALL_KICK_VX` / `WALL_KICK_VY` … 壁キックで飛ぶ強さ(横/上)
- `WALL_SLIDE_SPEED` … 壁ずりで落ちる速さ

### 背景テーマを変える
`themes.js` の `THEMES` 配列に、面ごとの空の色・霧・ビネット・浮遊粒子・タイルの配色がまとまっています。色を書き換えれば、その面の世界観を丸ごと変えられます。

### 効果音・BGM を変える
`audio.js` の `play()`(各効果音)と `startBGM()`(メロディの数値の並び)を変えると、音を調整できます。`play(name, pitch)` の第2引数で周波数の倍率を変えられ、ジャンプ音や着地音は勢いに応じて鳴き分けています。

### 収集・スコアの調整
`config.js` の次の値で、新要素の手ざわりを変えられます。
- `START_LIVES` / `MAX_LIVES` … 初期残機 / 残機の上限
- `COIN_SCORE` / `COIN_1UP` … コイン1枚の得点 / 何枚で1UPするか
- `STAR_FRAMES` … 無敵スターの効果時間(フレーム数。60で約1秒)
- `COMBO_BASE` / `COMBO_MAX_STEPS` … コンボ最初の得点 / 倍々にする上限段数

## 9. テスト

ブラウザを使わずに、設定・マップ解析・当たり判定など**描画に依存しない純粋ロジック**を検証する軽量テストを同梱しています(依存パッケージなし)。

```
npm test          # もしくは:  node tests/run.js
```

全27ステージが正しくパースできるか(15行・プレイヤー開始位置・ゴール/ボスの配置が index 8/17/26、コイン/スター/各パワーアップ/ギミックの存在、`x`/`w` が固体扱いされていないか)、全27面でテーマが割り当たること、`solidAt`/`hazardAt`/`windAt` の境界、`moveAndCollide` の落下・壁衝突、`overlaps`、`cliffAhead` などを確認します(計246項目)。マップや当たり判定をいじった後の**リグレッション検出**に使えます。
